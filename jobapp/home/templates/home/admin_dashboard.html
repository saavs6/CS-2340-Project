Export Details:
Core Data Exports:
  • All Users: User accounts with registration dates, user types, and activity status
  • Job Applications (Enhanced): Applications with full job details, applicant profiles, recruiter info, and pipeline status - perfect for funnel analysis
  • Job Postings (with Performance Metrics): Jobs with application counts, status breakdown, application rate per day, and recruiter details
  • Applicant Profiles (with Engagement): Applicants with application statistics, engagement frequency, skills count, and activity metrics
  • Recruiter Profiles (with Hiring Metrics): Recruiters with job posting statistics, application totals, conversion metrics, and company info
Analytics & Insights Exports:
  • Platform Usage Analytics: Comprehensive platform metrics including user counts, job stats, application conversion rates, and average metrics
  • Skills Supply vs Demand Analysis: Skills listed in jobs vs skills possessed by applicants, sorted by demand with supply/demand ratios
  • Daily Activity Trends: Day-by-day breakdown of new users, applicants, recruiters, jobs posted, and applications submitted (defaults to last 90 days)
  • Geographic Distribution: Location-based clustering of jobs, applicants, and recruiters by city, state, and country

Date Filtering: All exports support optional date range filtering. Analytics exports provide aggregated insights within the date range.
